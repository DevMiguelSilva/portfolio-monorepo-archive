# Archived monorepo architecture

The original workspace contained the Portfolio, ApplyTrack, and FitTrack apps in separate subdirectories. Their relevant histories have been extracted into independent repositories:

- [Portfolio](https://github.com/DevMiguelSilva/portfolio)
- [ApplyTrack](https://github.com/DevMiguelSilva/applytrack)
- [FitTrack](https://github.com/DevMiguelSilva/fittrack)

Each app now builds and deploys from its repository root. Product boundaries, application behavior, and independent databases are preserved. Historical architecture is available through this repository's Git history. See the active repositories for current setup instructions.
